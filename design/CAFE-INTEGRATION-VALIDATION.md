# 咖啡馆手绘 UI 实际插件接入

验证日期：2026-11-18。仅本地修改，没有提交或上传 GitHub。

## 已接入

- 咖啡馆手绘主题、小猫、本地持久化七种配色（原配色与六种可选色）。
- 顶部学习卡/清单导航，清单独立滚动，编辑状态与返回最初学习卡。
- 常规正文字体、深灰关键词、动态模型平台标签；悬停显示当前模型 ID。
- 中间阅读区独立滚动、长回答和长问题折叠；笔记固定可用高度，四个图文按钮同排。
- 真实复制初始解释（不含追问和笔记）；单卡下载和清单保存、合并导出包含解释、追问和笔记。
- 原句默认不发送；复选框只影响后续追问，不重新生成解释、不清空追问。取消后不再把原句作为上下文附带。已有模型回答中的引用仍属于对话历史。
- 去清单更新其他卡片再返回时，恢复原卡草稿、原句开关、展开状态与阅读位置。
- 关闭弹窗后忽略旧请求的迟到结果，避免覆盖新卡片。

- `npm run typecheck`：通过。

## 手动加载

在 Chrome / Edge 扩展管理页重新加载 `release/chrome-mv3`，然后刷新需要划词的网页。若尚未加载此目录，使用“加载已解压的扩展程序”选择该目录。

本次保留项目锁文件的依赖版本；安装时 npm 仍提示 10 项 high 级依赖审计告警，未在本次 UI 接入中升级依赖解决这些告警。
